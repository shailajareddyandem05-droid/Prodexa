# 🚀 PRODEXA — AI-Powered Productivity Platform

> A full-stack intelligent productivity dashboard that unifies tasks, notes, habits, scheduling, academic tracking, expenses, and AI-powered assistance into one seamless workspace.

---

## 📌 Overview

PRODEXA is a modern AI-powered productivity ecosystem designed to eliminate workflow fragmentation by integrating multiple productivity utilities into a single centralized dashboard.

Instead of switching between separate applications for tasks, notes, planning, analytics, and scheduling, PRODEXA provides everything inside one intelligent workspace enhanced with automation.

Designed especially for:

- Students
- Developers
- Professionals
- Researchers
- Productivity-focused users

---

## ✨ Features

### 📋 Task Management
Create, update, prioritize, and organize tasks with structured tracking support.

### 🧠 AI Assistant
Generate tasks, summarize notes, organize ideas, and improve productivity workflows using intelligent automation.

### 📝 Notes Manager
Structured note storage with editing and organizational support.

### 📅 Calendar Planner
Manage schedules and events in a centralized interface.

### 📧 Mail Integration
Access email workflows directly inside the dashboard environment.

### 📊 Expense Tracker
Track spending and maintain structured financial records.

### 🎯 Focus Mode
Dedicated distraction-free productivity sessions.

### ⏱ Pomodoro Timer
Built-in Pomodoro workflow for time-block productivity.

### 📈 Habit Tracker
Monitor consistency with habit streak tracking.

### 🎓 GPA Calculator
Academic performance tracking with automated GPA computation.

### 🧩 Brain Dump Organizer
Convert unstructured thoughts into actionable structured plans.

## 🏗 System Architecture

PRODEXA follows a scalable full-stack architecture:

- Frontend handles UI rendering and user interaction
- Backend manages APIs and integrations
- Firestore handles structured cloud data storage
- Authentication handled securely via Firebase

## ⚙️ Environment Setup

### Backend Setup

```
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

### Frontend Setup

```
cd frontend
npm install
npm run dev
```
